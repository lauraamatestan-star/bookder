# Project Management - Bookder

## Metodología

Utilizamos un enfoque **Kanban** adaptado para proyectos escolares, gestionando el trabajo a través de un tablero de Trello.

## Tablero Trello

### Columnas del Board

| Columna | Descripción |
|---------|-------------|
| **Backlog** | Ideas y tareas pendientes sin asignar |
| **To Do** | Tareas priorizadas listas para iniciar |
| **In Progress** | Tareas en desarrollo activo |
| **Review** | Tareas completadas esperando revisión |
| **Done** | Tareas finalizadas y verificadas |

## Flujo de Trabajo

```
Backlog → To Do → In Progress → Review → Done
```

### Reglas

1. **Backlog**: Cualquier miembro puede agregar tarjetas con descripción
2. **To Do**: El líder del sprint prioriza y mueve las tareas más urgentes
3. **In Progress**: Solo una tarea por persona para evitar multitasking
4. **Review**: Requiere revisión de otro compañero antes de marcar Done
5. **Done**: Tareas completadas, listas para demostración

## Sprint Planning

- **Duración**: 1 semana
- **Reunión**: Lunes - Definir objetivos del sprint
- **Review**: Viernes - Demostrar avances

## Etiquetas Trello

- 🔴 Urgente
- 🟡 Feature
- 🟢 Bug
- 🔵 Documentación
- 🟣 Diseño

## Ejemplo de tarjetas

- Página de libros
- Sistema de trueques (tipo Tinder)
- Carrito de compra
- API de pago y transporte
- Cambiar idioma
- Seguridad al comprar
- Suscripción por trueques

El enlace al tablero Trello está incluido en el README del proyecto.
