# Reflexión final sobre Bookder

## Aprendizajes
- Integración de frontend (React/TypeScript), backend (Express) y API REST
- Importancia de la documentación y la organización ágil
- Gestión de tipos y contratos de datos entre cliente y servidor
- Uso de Context API y custom hooks para estado global y reutilización

## Problemas encontrados
- Sincronización de tipos entre frontend y backend
- Manejo de errores en la capa de red
- Integración de despliegue y variables de entorno

## Uso de IA
- Apoyo en generación de documentación, código y resolución de dudas
