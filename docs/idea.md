# Idea del Proyecto: Bookder

## Descripción general
Bookder es una plataforma web para comprar, vender, intercambiar y descubrir libros de segunda mano o nuevos. Busca conectar a lectores y facilitar el acceso a libros mediante funcionalidades sociales y de comercio.

## Problema que resuelve
- Dificultad para encontrar libros de segunda mano en buen estado y a buen precio.
- Falta de plataformas que combinen compra, venta, intercambio y recomendaciones personalizadas.
- Necesidad de una comunidad de lectores con intereses afines.

## Usuario objetivo
- Lectores de todas las edades interesados en comprar, vender o intercambiar libros.
- Personas que buscan libros específicos o desean descubrir nuevas lecturas según sus intereses.

## Funcionalidades principales
- Catálogo de libros con filtros por género, autor, estado, etc.
- Compra y venta de libros.
- Intercambio de libros entre usuarios (trueques).
- Sistema de recomendaciones basado en intereses y "me gusta".
- Carrito de compra/cesta.
- Gestión de usuarios y perfiles.
- Etiquetas de estado: "nuevo", "usado", "muy buscado".
- Página de inicio, catálogo, carrito, subir libro, perfil y página 404.

## Funcionalidades opcionales
- Filtro automático por intereses (género favorito, autores preferidos).
- Match por proximidad (si los usuarios aceptan poner ciudad).
- Match por disponibilidad (solo mostrar intercambios activos).
- Pujas para libros muy demandados.
- Recomendaciones automáticas según "me gusta".
- Cambiar idioma (inglés/francés).
- Integración con APIs externas de libros.
- Animaciones, drag & drop, lazy loading.

## Mejoras futuras
- Sistema de likes y recomendaciones con scroll infinito.
- Integración de pagos (Stripe/PayPal) y envíos (Shippo).
- Seguridad en las transacciones (como Wallapop).
- Suscripción premium para ventajas en trueques.
- Testing automatizado y documentación con Swagger/OpenAPI.
